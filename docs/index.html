介绍

pinapp 让你把截图「钉」在屏幕上:按下系统截图键截取画面后,再按一个热键, 截图就会作为始终置顶的悬浮窗贴在桌面,方便对照代码、比对设计稿、做「半透明小抄」。

Print 截图 → dms screenshot(进剪贴板) → Pause 钉图 → 置顶悬浮窗

GitHub 仓库 · 下载 Release

特性

置顶贴图

浮动窗口天然置于平铺窗口之上,多张并存。

自由操控

拖动移动、滚轮缩放、Ctrl+滚轮调透明度。

旋转翻转

90° 旋转、水平/垂直翻转随心切换。

鼠标穿透

一键切换点击穿透(受合成器支持限制)。

安装

从 Release 下载

到 Releases 下载对应架构的 pinapp-<target>.tar.gz,解压后将 pinapp 放到 PATH 中。

从源码构建

# 依赖(Ubuntu / Debian 示例)
sudo apt install -y libclang-dev libgtk-3-dev libxkbcommon-dev \
  libwayland-dev libfontconfig1-dev libfreetype6-dev pkg-config libssl-dev
# wl-clipboard(dms 已自带,用于剪贴板读取)
sudo apt install -y wl-clipboard

cargo build --release
# 产物:target/release/pinapp

快速开始

  1. 按 Print 截图(dms 默认,截图自动进剪贴板)。
  2. 按 Pause 钉图。每按一次新增一张贴图。
  3. 拖动、缩放、调透明度,或按 Esc 关闭当前贴图。
提示:需在 niri 中把 Pause 绑到 pinapp --pin,并让 pinapp 随会话自启(守护进程)。详见下方配置。

快捷键

按键作用
拖动窗口移动
滚轮缩放
Ctrl + 滚轮调透明度
R / Shift+R顺时针 / 逆时针旋转 90°
F / V水平 / 垂直翻转
T切换鼠标穿透
Esc关闭当前贴图

niri 配置

把以下内容加入 ~/.config/niri/config.kdl:

# 让贴图窗口以浮动方式打开(天然置顶于平铺窗口之上)
window-rule {
    match app-id="pinapp"
    open-floating true
}

# 把 Pause 绑到 pinapp --pin(每个 spawn 参数独立加引号)
binds {
    Pause { spawn "pinapp" "--pin"; }
}

开机自启:把 pinapp(无参数 = 守护进程)加入 niri 的 spawn-at-startup 或 systemd --user。

niri 的键位语法请以你当前 niri 版本为准。若想在截图后自动贴图,可用 Pause { spawn "sh" "-c" "dms screenshot && pinapp --pin"; }(niri ≥ 25.08 亦可写 spawn-sh "dms screenshot && pinapp --pin")。

常见问题

鼠标穿透为什么不生效?

穿透通过 Wayland 的输入区域(input region)实现:常态下只有图片矩形接收指针事件,按 T 后整个表面都设为空输入区,点击会穿透到下层窗口。若无效,请确认会话是真正的 Wayland 会话(echo $WAYLAND_DISPLAY 有值),而非 XWayland。

支持其它合成器吗?

本程序面向 niri / Wayland 设计;其它 Wayland 合成器需自行验证窗口置顶与键位绑定。

截图从哪来?

由 danklinux 默认的 dms screenshot 提供,默认复制到剪贴板;pinapp 通过剪贴板读取图片。
