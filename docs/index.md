pinapp 让你把截图「钉」在屏幕上:按下系统截图键截取画面后,再按一个热键,截图就会作为
**始终置顶的悬浮窗**贴在桌面,方便对照代码、比对设计稿、做「半透明小抄」。

取图链路:

> **Print** 截图 → `dms screenshot`(进剪贴板) → **Pause** 钉图 → 置顶悬浮窗
